# Financial Variance Command Center

**Every variance deserves a theory.**

A transparent multi-agent research prototype that extends the Site Financial Health Engine from standardized reporting into accountable variance investigation.

[Launch the public application](https://fa366193.github.io/financial-variance-command-center/) · [Read the research notebook](https://decisionsystemslab.org/systems/site-financial-health-engine) · [Download the technical report](https://fa366193.github.io/financial-variance-command-center/financial-variance-command-center-technical-report.pdf) · [Watch the narrated demo](https://fa366193.github.io/financial-variance-command-center/financial-variance-command-center-video-demo.mp4)

## Agent team

- Data Steward validates source completeness and mappings.
- Variance Analyst decomposes volume, rate, mix, and timing.
- Operations Liaison connects financial movement to operational signals.
- Forecast Challenger contests the outlook and alternate baselines.
- Risk Auditor checks control, cutoff, and anomaly exposure.
- Finance Synthesizer prepares a human-reviewable management brief.

## Current research boundary

The public release is a deterministic browser simulation using synthetic data. It does not connect to SAP or Power BI, call external language models, post journal entries, or claim measured organizational impact.
